# 2주차 실습 — 학습률 실패 진단

## 목표

NumPy만 사용해 선형 모델 $\hat{y}=wx+b$를 학습시키는 프로그램을 구현한다. 같은 데이터와 같은 수식에서 학습률만 바꿨을 때 손실이 어떻게 변하는지 실행 기록으로 확인한다.

AI에게 코드 초안을 요청해도 된다. 다만 학생은 수식과 고정 검증값으로 AI의 결과를 확인하고, 직접 관찰한 결과의 이유를 남긴다.

## 제공 데이터와 수식

`data/linear_train.csv`에는 공부시간 $x$와 점수 $y$가 다음처럼 들어 있다.

| $x$ | $y$ |
|---:|---:|
| -2 | 4 |
| -1 | 1 |
| 0 | 0 |
| 1 | 1 |
| 2 | 4 |

사용할 모델과 손실은 고정한다.

$$\hat{y}_i=wx_i+b$$

$$L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)^2$$

$$\frac{\partial L}{\partial w}=\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)x_i,\qquad
\frac{\partial L}{\partial b}=\frac{2}{n}\sum_{i=1}^{n}(\hat{y}_i-y_i)$$

$$w\leftarrow w-\eta\frac{\partial L}{\partial w},\qquad b\leftarrow b-\eta\frac{\partial L}{\partial b}$$

여기서 $\eta$는 학습률이고, 모든 실험은 $w=0$, $b=0$에서 시작해 정확히 20회 갱신한다.

## 실험과 열린 목표

먼저 기준선으로 $\eta=0.01$을 20회 실행한다. 이어서 서로 다른 학습률을 최소 세 개 더 실행한다. 각 실행의 손실 증가 여부와 마지막 손실을 `result.txt`와 `learning_log.csv`에서 확인한다.

열린 목표는 **20회 뒤 MSE를 `1.0` 이하로 낮추는 학습률을 찾는 것**이다. 각 후보의 손실 증가 여부와 최종 MSE를 표로 남기고, 목표를 만족한 후보가 있으면 그 후보를 선택한다.

`README.md`의 `학습률 실험과 실패 원인`에는 최소 세 후보의 최종 손실과 증가 여부를 표로 남긴다. 이어서 관찰한 목표 달성 또는 미달성의 이유를 모델의 표현 범위와 데이터의 관계로 **한 문장**으로 쓴다.
