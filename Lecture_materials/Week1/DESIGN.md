# Kami Academic · 생성형 AI 배포용

- Surface: parchment `#F5F4ED`, ivory panels `#FAF9F5`
- Accent: ink blue `#1B365D` only; cover and Summary are the only dark slides
- Type: Korean serif titles at weight 500, Pretendard/Noto Sans KR body, JetBrains Mono for code and metadata
- Layout: 1920×1080, one `##` per slide, `###` sections become panels within that slide
- Content: source order, tables, equations, code, figures, and captions are preserved without adding claims
- Interaction: arrows, PageUp/PageDown, Space, Home/End, wheel, touch, ESC overview, localStorage, print CSS

The visual language is adapted from the locally cached Open Design `kami-deck` template and its MIT-inspired upstream design.
