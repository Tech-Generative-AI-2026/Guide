데이터와 설계

  • 제공된 합성 언어 데이터로 모델을 학습한다.
  • 모델 구조·학습 알고리즘·학습률·규제 방법을 직접 설계한다.

  • 프로젝트 세부 제출 형식과 평가 코드는 별도 공지를 따른다.

생성형 AI와 텍스트 생성

텍스트 생성 문제

  • 텍스트 생성은 앞에 주어진 문맥에 이어질 글자나 단어 조각을 반복해서 선택하는 일이다.
  • 가능한 문장 수가 매우 많아 사람이 모든 입력과 답을 미리 작성할 수 없다.

생성형 AI의 역할

  • 생성형 AI는 많은 예제에서 다음에 올 표현의 확률을 학습하고 새 문맥에서 후보를 선택한다.
  • 자연스러운 출력은 사실성·안전성·정확성을 자동으로 보장하지 않으므로 별도 검증이 필요하다.

문제와 현재 해법 — 왜 텍스트 생성에 생성형 AI를 사용하는가?

중심 문제와 현재 해법

  • 중심 문제는 사람이 모든 문장 규칙을 작성하지 않고 새 문맥에 이어지는 텍스트를 만드는 것이다.
  • 현재 해법은 Transformer 기반 생성형 AI가 앞 문맥에서 다음 토큰 확률을 학습하고 선택을 반복하는 것이다.

효과와 연결 질문

  • 같은 모델은 입력 문맥과 선택 결과에 따라 훈련 문장을 그대로 복사하지 않은 새로운 문장을 만들 수 있다.
  • 그렇다면 왜 텍스트 생성에는 미리 작성한 규칙보다 Transformer 기반 생성형 AI를 사용하는가?

Summary

강의 진행

  • 전반부는 학습 원리와 GPT 구조, 후반부는 언어모델 학습·생성·미세조정으로 진행한다.
  • 평가는 중간고사와 제한 조건이 있는 기말프로젝트·발표·참여 기록으로 구성한다.
  • 프로젝트는 제공된 합성 언어 데이터와 직접 설계한 작은 모델만 사용한다.

왜 생성형 AI인가

  • 텍스트 생성은 앞 문맥에 이어질 글자나 단어 조각을 반복해서 선택하는 일이다.
  • Transformer 기반 생성형 AI는 앞 문맥에서 다음 토큰의 확률을 계산하고 선택을 반복한다.
  • 자연스러운 출력도 사실성·안전성·정확성을 자동으로 보장하지 않으므로 별도 검증이 필요하다.
