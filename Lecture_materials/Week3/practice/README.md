# 3주차 실습 — 텍스트를 임베딩 벡터로 바꾸기

## 실습 목표

작은 코퍼스에서 BPE 병합을 한 번 수행하고, `newest`를 토큰 ID 열로 바꾼 뒤 임베딩 표에서 벡터를 조회하는 Python 프로그램을 구현한다. **아래 세 단계는 모두 하나의 실습에 포함된다.** AI로 코드를 작성해도 된다. 읽기 쉬운 `main.py` 한 파일, 빈 줄과 주석을 포함해 100줄 이내로 해결할 수 있다.

## 입력과 처리

1. 제공하는 [`data/corpus.txt`](data/corpus.txt)를 읽는다. 한 줄이 단어 한 번의 등장이다. 각 줄의 단어를 글자와 단어 끝 기호 `</w>`로 나누고, 바로 이웃한 기호 쌍의 빈도를 센다. 같은 단어가 여러 줄 있으면 그 횟수만큼 쌍도 반복해서 센다.

   ```text
   low     → l o w </w>
   lower   → l o w e r </w>
   newest  → n e w e s t </w>
   widest  → w i d e s t </w>
   ```

   최빈 쌍이 여럿이면 기호 두 개의 **사전순**으로 가장 앞선 쌍을 선택한다. 첫 병합은 `(e, s)`의 빈도 9회이며, 두 단어의 `e s`를 `es`로 바꾼다. 병합 전의 `(s, t)`도 9회이므로 동률 규칙을 반드시 적용한다.

2. 병합 규칙 `e+s→es`를 입력 단어 `newest`에 적용한다. 결과 `n e w es t </w>`의 기호를 아래 고정 사전에서 조회해 ID 열을 만든다.

   | 토큰 | `n` | `e` | `w` | `es` | `t` | `</w>` |
   |---|---:|---:|---:|---:|---:|---:|
   | ID | 0 | 1 | 2 | 3 | 4 | 5 |

3. 각 ID로 아래 임베딩 표의 **같은 번호 행**을 조회한다. 행마다 숫자 두 개가 있으므로 결과는 토큰 여섯 개의 2차원 벡터 열이다. 이 표의 값은 실습용 고정값이다.

   | ID | 벡터 |
   |---:|---|
   | 0 | `[1, 0]` |
   | 1 | `[0, 1]` |
   | 2 | `[1, 1]` |
   | 3 | `[2, 0]` |
   | 4 | `[0, 2]` |
   | 5 | `[2, 2]` |

## 기대 출력

`python main.py`를 실행해 다음을 확인한다. 출력 형식은 자유롭게 정해도 되지만 값과 순서는 같아야 한다.

```text
선택한 쌍: ('e', 's'), 빈도: 9
병합 뒤 newest: ['n', 'e', 'w', 'es', 't', '</w>']
토큰 ID: [0, 1, 2, 3, 4, 5]
임베딩: [[1, 0], [0, 1], [1, 1], [2, 0], [0, 2], [2, 2]]
```

## 제출

학생 저장소의 `Week03/`에 `main.py`, 제공된 `data/corpus.txt`, 실제 실행 출력을 복사한 `result.txt`를 제출한다. Python 소스는 `main.py` **한 개만** 제출하고 빈 줄·주석을 포함해 **100줄 이내**로 작성한다. 소스 코드 틀은 제공하지 않는다. `Week03/`에서 `python main.py`를 실행하면 `data/corpus.txt`를 읽고 결과를 화면에 출력해야 한다. `result.txt`에 화면 출력을 저장할 때는 기존 파일을 덮어쓰지 않도록 확인한다.
