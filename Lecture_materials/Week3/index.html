생성형 AI —
텍스트 표현과 신경망 학습

문자열을 계산 가능한 벡터로 바꾸고, 오차를 따라 파라미터를 고치는 전체 흐름

텍스트의 계산 표현

  • 문자열을 토큰으로 나누고 각 토큰을 사전의 정수 주소인 토큰 ID로 바꾼다.
  • BPE가 자주 붙는 이웃 기호를 병합해 사전 크기와 토큰 수를 절충하는 과정을 계산한다.
  • 학습 코퍼스의 언어 구성이 언어별 토큰 분절과 문맥 비용을 바꾸는 이유를 비교한다.

파라미터의 학습

  • 토큰 ID로 임베딩 표의 행을 조회해 신경망이 계산할 벡터를 얻는다.
  • 선형층 사이에 비선형 활성함수를 넣어 직선 하나보다 복잡한 관계를 표현한다.
  • 순전파로 예측과 손실을 계산하고 역전파로 각 파라미터의 기울기를 구한다.

토큰 사전에서 나온 ID 열

[40, 1842, 9552]의 출처

  • 신경망은 문자열 자체가 아니라 숫자 배열을 곱하고 더하므로, 먼저 문자열을 계산 가능한 주소와 벡터로 바꾼다.
  • 토크나이저는 문장을 I, love, AI라는 세 토큰으로 나눈다.

  • 세 주소를 문장 순서대로 모으면 신경망에 전달할 ID 열이 된다.

06 · COMPARE

토큰 ID의 범주형 성격

하면 안 되는 계산

  • 1842 > 40은 love가 I보다 중요하다는 뜻이 아니다.
  • 1842-40=1802도 두 토큰의 의미 거리가 아니다.
  • ID는 크기를 재는 값이 아니라 항목을 구분하는 주소이다.

실제로 하는 계산

  • E[40]은 I의 임베딩 행을 조회한다.
  • E[1842]는 love의 임베딩 행을 조회한다.
  • 의미 관계는 ID 숫자가 아니라 조회된 학습 벡터에서 계산한다.

단어 단위 토큰화의 한계

사전에 없는 단어

  • 단어마다 ID 하나를 주면 신조어·오타·고유명사가 늘어날 때 사전도 계속 커진다.
  • 사전에 없는 단어를 하나의 미지 토큰으로 바꾸면 서로 다른 문자열의 정보가 같은 ID로 사라진다.
  • play, played, playing을 모두 별도 항목으로 두면 공유하는 형태를 토큰 단계에서 활용하기 어렵다.

사전에 없는 단어playful → [UNK]
playroom → [UNK]

play라는 공통 조각을 재사용하지 못하는 것이 단어 단위 방식의 한계다.

문자 토큰이 늘리는 처리량

cats run의 쉬운 비교

  • 단어 단위는 [cats][run]의 2개, 문자 단위는 공백까지 포함해 8개 토큰이다.
  • 문자 방식은 임베딩 표에서 2행이 아니라 8행을 조회하고 뒤 계산도 8개 위치를 처리한다.
  • 모든 위치 쌍을 비교하는 자기어텐션에서는 점수 칸이 T²에 비례해 늘어난다.
단어 단위 · T=2[cats] [run]
임베딩 2개
비교 칸 2²=4
문자 단위 · T=8[c][a][t][s][␠][r][u][n]
임베딩 8개
비교 칸 8²=64
토큰 4배 → 이 예의 어텐션 비교 칸 16배

BPE의 최빈 이웃 쌍 병합

핵심 규칙

  • BPE(Byte Pair Encoding)는 현재 코퍼스에서 바로 이웃한 기호 쌍의 등장 횟수를 센다.
  • 가장 자주 등장한 쌍을 새 기호로 합치고 코퍼스의 해당 쌍을 모두 치환한다.
  • 정한 병합 횟수만큼 반복한 뒤 최종 사전과 순서가 있는 병합 규칙을 저장한다.

글자 BPE와 바이트 수준 BPE의 차이

왜 지금 바이트를 배우는가

  • 앞 BPE는 글자를 초기 기호로 삼으므로 글자 사전에 없는 새 문자는 시작조차 못 할 수 있다.

임베딩 표

  • 임베딩 표 $E$는 행마다 한 토큰의 학습 가능한 실수 벡터를 저장한 행렬이다.
  • 어휘 수를 $V$, 임베딩 차원을 $d$라고 하면 $E$의 모양은 (V, d)이다.
  • 토큰 ID $i$의 임베딩은 행렬곱이 아니라 $E$의 $i$번째 행을 선택한 벡터 $E[i]$이다.

18 · SHAPE

임베딩 Shape의 위치별 의미

(B,T,d)를 왼쪽부터 읽기

  • B는 한 번에 처리할 문장 수, T는 문장마다 맞춘 토큰 수이다.
  • d는 토큰 하나를 나타내는 임베딩 숫자 좌표 수이다.
  • 문장 1개·토큰 3개·좌표 4개이므로 (1,3)→(1,3,4)가 된다.
B = 1첫째I love AI 문장 한 개
T = 3둘째I · love · AI 세 토큰
d = 4셋째각 토큰 벡터의 실수 네 개
import torch

ids = torch.tensor([[40, 1842, 9552]])  # (1, 3)
emb = torch.nn.Embedding(10000, 4)
x = emb(ids)

print(ids.shape)  # torch.Size([1, 3])
print(x.shape)    # torch.Size([1, 3, 4])

비선형 활성함수의 역할

ReLU의 구간 선택

  • ReLU(z)=max(0,z)는 음수 구간을 0으로 막고 양수를 유지한다.
  • ReLU(-2)=0, ReLU(3)=3으로 입력 구간마다 다른 규칙이 적용된다.
  • 이 꺾임 때문에 앞뒤 선형층을 하나의 선형식으로 합칠 수 없다.

Sigmoid의 확률 출력

  • Sigmoid는 모든 실수를 0과 1 사이 값으로 바꾼다.
  • Sigmoid(0)=0.5는 두 범주 사이의 중간 확률이다.
  • 출력에 0.5 기준을 적용하면 이진 범주를 판정할 수 있다.

예측값에 대한 손실의 기울기

손실에서 예측으로

  • 원래 식은 L=(ŷ-y)²이며, 예측 ŷ가 바뀔 때 손실의 변화를 구한다.
  • 제곱 미분 (u²)'=2u에 u=ŷ-y를 넣어 2(ŷ-y)가 된다.
  • 음수 결과는 현재 예측을 키우면 손실이 줄어드는 방향임을 뜻한다.
\[\frac{\partial L}{\partial\hat y}=2(\hat y-y)\]
\[2(-0.111230-2.1)=\boxed{-4.422459}\]

loss.backward()             # .grad에 기울기 누적
optimizer.step()            # 파라미터 갱신

  • Linear(2,4)는 두 입력을 네 개의 은닉 특성으로 바꾼다.
