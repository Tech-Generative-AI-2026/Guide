# Self-Attention 계산 검증 리포트

## 실습 목표

같은 문장의 여섯 토큰 벡터로 비교 점수(score), 기여 비율(attention weight), 문맥 벡터(context vector)를 계산한다. 구현을 검토할 동료가 같은 결과를 재현할 수 있도록 `attention_report.py` 한 파일을 완성한다. 학습 가능한 투영이나 모델 훈련은 포함하지 않는다.

## 제공 입력과 환경

Python과 PyTorch를 사용하는 수업 실습 환경에서 실행한다. 학생에게 제공하는 파일은 이 안내를 옮긴 `README.md`와 `inputs.csv`뿐이다. 아래 표가 `inputs.csv`의 전체 데이터이며, 각 행은 토큰 하나, 세 숫자는 그 토큰의 예시 특징 좌표다. 이 숫자가 학습된 단어 의미를 나타낸다고 가정하지 않는다.

```csv
token,f1,f2,f3
Your,0.43,0.15,0.89
journey,0.55,0.87,0.66
starts,0.57,0.85,0.64
with,0.22,0.58,0.33
one,0.77,0.25,0.10
step,0.05,0.80,0.55
```

입력은 소스 안에 같은 순서로 적어도 된다. CSV를 직접 읽는 방식도 허용하지만 추가 라이브러리는 필요 없다. 계산에는 32비트 실수를 사용한다. AI를 코드 초안 작성에 사용할 수 있으며, 최종 결과는 직접 실행해 확인한다.

## 처리 순서와 성공 기준

1. 토큰 순서와 입력 행렬 `X`를 준비한다. `X.shape`이 `[6,3]`인지 확인한다. 이 행 순서는 이후 점수의 행·열, 기여 비율의 행·열, 문맥 벡터의 행에 동일하게 대응한다.
2. 두 번째 토큰 `journey`를 기준으로 입력 여섯 개와 내적해 점수 여섯 개를 만든다. 첫 점수는 `0.9544`다. 여섯 점수에 softmax를 적용하고 그 비율로 입력 벡터를 가중합해 문맥 벡터 하나를 계산한다.
3. 모든 토큰을 기준으로 점수 행렬 `S = X @ X.T`를 만든다. 각 행에 별도로 softmax를 적용해 `A`를 만들고 `Z = A @ X`를 계산한다. `A`의 행은 기준 토큰, 열은 기여하는 입력 토큰이다.
4. 토큰 순서, `A`, `Z`, 각 행렬의 shape, `A` 각 행의 합, 검산 결과를 터미널에 출력한다. 검산은 음수 비율이 없는지, 각 행 합이 1인지, 전체 계산의 두 번째 행이 단일 토큰 계산과 같은지 확인한다.

**작은 기대 출력:** 두 번째 점수는 `[0.9544,1.4950,1.4754,0.8434,0.7070,1.0865]`, 비율은 약 `[0.1385,0.2379,0.2333,0.1240,0.1082,0.1581]`, 문맥 벡터는 약 `[0.4419,0.6515,0.5683]`이다. `A.shape=[6,6]`, `Z.shape=[6,3]`, 각 행의 합은 약 `[1,1,1,1,1,1]`이어야 한다.

계산 도중 값을 반올림하지 않는다. 반올림은 출력할 때만 적용한다. 행 합과 단일·전체 계산 비교에는 `torch.allclose(..., atol=1e-6, rtol=0)`을 사용한다. `atol`은 절대 허용 오차, `rtol=0`은 추가 상대 오차를 허용하지 않는다는 뜻이다. 표시된 소수 넷째 자리 값과 비교할 때는 표시 오차를 별도로 고려한다.

## 제출 파일과 실행

학생 저장소의 `Week05/`에 `attention_report.py` 한 파일을 제출한다. 빈 줄과 주석을 포함한 실제 줄 수가 100줄 이하여야 한다. 입력을 CSV에서 읽었다면 제공된 `inputs.csv`도 같은 제출 commit에 포함하고 같은 폴더에서 실행되도록 한다. 데이터 파일은 제공 입력이며 추가 Python 소스로 세지 않는다.

```bash
python attention_report.py
```

이 명령은 현재 폴더의 Python 소스를 읽어 실행하고 검증 리포트를 터미널에 출력한다. CSV를 읽는 구현은 같은 폴더의 `inputs.csv`도 읽는다. 파일 저장이나 덮어쓰기는 요구하지 않는다. 터미널 출력의 행 합과 단일·전체 계산 비교가 통과하는지 확인한다.

별도 고찰 문서나 실행 결과 파일은 제출하지 않는다. 개인 이해도는 실습 종료 후 교수자의 현장 확인과 Discord 비공개 서술형 문항으로 별도 확인한다.
