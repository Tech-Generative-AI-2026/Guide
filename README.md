## 5주차 실습 제출·마감 공지

**2026년 10월 8일(목) 10:30(KST)까지 개인 저장소에 push를 완료한다. 10:31(KST)부터 push 권한을 일괄 회수한다.** 서술형 퇴실 답안을 제출하면 제출 직후 본인 저장소의 push 권한이 회수되므로, 답변 전에 모든 제출물을 push한다. 서술형 응시를 위해 **11:00(KST)까지 교수자 앞으로 나와야 한다.**

제출 파일: `Week05/attention_report.py`(100줄 이내). 입력을 CSV에서 읽으면 `Week05/inputs.csv`도 함께 제출한다.
