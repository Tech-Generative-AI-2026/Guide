## 7주차 실습 제출·마감 공지

**2026년 10월 29일(목) 10:50(KST)까지 개인 저장소에 push를 완료한다. 10:51(KST)부터 push 권한을 일괄 회수한다.** 서술형 문제는 다음 실습 수업 시작 직후 전원이 함께 응시하며, 마감 시점에 push된 `Week07/` 코드가 문제와 채점의 기준이다. push 권한은 다음 서술형 응시와 평가가 끝날 때까지 닫혀 있다. 서술형 시작 시각 전에 UCheck 출석 또는 지각 기록이 없으면 응시하더라도 0점이다.

제출 파일: `Week07/gpt_forward.py`(100줄 이내)와 제공 파일 `Week07/gpt_weights.json`.
