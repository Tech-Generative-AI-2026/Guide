## 6주차 실습 제출·마감 공지

**2026년 10월 15일(목) 10:30(KST)까지 개인 저장소에 push를 완료한다. 10:31(KST)부터 push 권한을 일괄 회수한다.** 서술형 문제는 다음 주 수업 시작 30분 후 전원이 함께 응시하며, 마감 시점에 push된 `Week06/` 코드가 문제와 채점의 기준이다. push 권한은 다음 주 서술형 응시와 평가가 끝날 때까지 닫혀 있다. 서술형 시작 시각 전에 UCheck 출석 또는 지각 기록이 없으면 응시하더라도 0점이다.

제출 파일: `Week06/attention_check.py`(100줄 이내). JSON을 읽도록 구현했다면 `Week06/example.json`도 함께 제출한다.
