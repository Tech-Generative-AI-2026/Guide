## 목표와 전달물

토큰 세 개의 입력으로 두 head의 causal self-attention을 계산하고, 각 토큰이 미래 토큰을 읽지 않는다는 사실을 실행 결과로 확인한다. 동료 개발자가 실행해 같은 결과를 재현할 수 있는 `attention_check.py` 한 개를 완성한다. Q·K·V 변환, 스케일 점수, causal mask, softmax, Value 가중합, 두 head 출력의 연결을 하나의 실행 흐름에 넣는다.

## 제공 입력과 환경

Python과 PyTorch를 사용한다. GPU는 필요하지 않다. 예시 구현은 Python 3.11, PyTorch 2.7.0 CPU에서 실행했다.

제공 파일은 `README.md`와 `example.json`이다. 실행할 Python 파일은 직접 작성한다. AI로 코드 초안을 작성해도 되며, 실제 출력과 검증 결과는 직접 확인한다.

예제는 “나는 / 차를 / 마신다”를 세 토큰으로 정한 계산용 입력이다. 실제 tokenizer 결과나 학습된 임베딩이 아니다. 행은 토큰, 열은 특징이며 모든 값을 실수(float32) 텐서로 만든다.

| 대상 | 값 | shape | 역할 |
|---|---|---|---|
| X | `[[1,0],[0,1],[1,1]]` | (3,2) | 토큰 3개의 입력. 행 순서는 나는 / 차를 / 마신다 |
| head 1의 `W_Q` | `[[1,0],[0,1]]` | (2,2) | Query(찾을 정보)를 만드는 계수 |
| head 2의 `W_Q` | `[[0,1],[1,0]]` | (2,2) | head 2의 Query 계수 |
| 두 head의 `W_K` | `[[1,1],[0,1]]` | (2,2) | Key(비교할 특징)를 만드는 계수 |
| 두 head의 `W_V` | `[[1,2],[3,0]]` | (2,2) | Value(전달할 내용)를 만드는 계수 |
| 바꿀 셋째 토큰 | `[9,-4]` | (2,) | 미래 차단 검증에 쓰는 변경 입력 |

모든 변환은 `Q = X @ W_Q`처럼 X의 오른쪽에 W를 곱한다. 실제 모델에서 W는 학습되는 파라미터지만, 이 실습에서는 표의 값으로 고정해 계산한다. Dropout은 학습 중에만 적용하고 평가 때 끄므로 이 실습의 계산에는 넣지 않는다. 두 head를 연결한 Z (3,4)를 최종 출력으로 사용한다.

## 처리 순서

1. X와 W 값을 실수 텐서로 준비한다. `example.json`을 읽거나 표의 값을 소스에 직접 넣어도 된다.
2. head마다 `Q = X @ W_Q`, `K = X @ W_K`, `V = X @ W_V`를 계산한다. 세 결과의 shape은 모두 (3,2)다.
3. head마다 점수 `S = Q @ K.T`를 계산하고 √d_k = √2로 나눈다. `d_k`는 Key 벡터 하나의 특징 수다. 점수 행렬의 행은 Query 위치, 열은 Key 위치다.
4. 대각선 바로 위부터 True인 3×3 causal mask를 만든다. True인 미래 위치의 점수만 −∞로 바꾼 뒤, 각 행의 Key 열 방향으로 softmax를 적용해 attention 비율 A를 만든다. 현재 위치(대각선)는 차단하지 않는다.
5. head마다 `Z_h = A_h @ V_h`로 문맥 벡터를 계산한다. 같은 토큰의 행끼리 head 1의 두 특징 다음 head 2의 두 특징을 이어 붙여 Z (3,4)를 만든다.
6. 입력의 셋째 토큰만 `[9,-4]`로 바꿔 같은 계산을 다시 실행한다. 앞 두 토큰의 출력은 그대로이고 셋째 토큰의 출력만 달라지는지 검사한다. 부동소수점 비교는 절대 오차 `1e-6`을 허용한다.
7. 각 head의 A에서 모든 행의 합이 1이고 mask가 True인 미래 위치의 비율이 모두 0인지 검사한다.

## 실행과 확인

작업 폴더에서 다음 명령을 실행한다.

```bash
python attention_check.py
```

명령은 작성한 소스를 읽어 계산하고 터미널에 결과를 출력한다. JSON을 읽도록 구현했다면 같은 폴더의 `example.json`도 읽는다. 제공 파일을 덮어쓰거나 별도 결과 파일을 만들 필요는 없다.

다음 값과 판정이 출력에 포함되어야 한다. 출력 문구와 배치는 자유다.

```text
output_shape: (3, 4)
second_token: [2.0, 1.0, 1.6605, 1.3395]
prefix_unchanged: True
last_changed: True
causal_rows_and_zeros: PASS
```

`second_token`은 둘째 토큰 “차를”의 출력이며, 순서는 head 1의 두 특징 다음 head 2의 두 특징이다. head 1에서 “차를”의 스케일 점수는 `[0.7071, 0.7071, 1.4142]`이고, 미래 “마신다”를 차단한 뒤의 비율은 `[0.5, 0.5, 0]`이다. 이 비율로 Value 두 행 `[1,2]`, `[3,0]`을 섞으면 `[2.0, 1.0]`이 된다. 출력 값은 소수 넷째 자리까지 반올림해 표시하며, 계산 도중에는 반올림하지 않는다.
