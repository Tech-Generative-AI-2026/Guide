## 점수와 시험 손실은 어떻게 다를까요?

최종 점수(score)는 모델이 **실제로 쓴 답**을 채점합니다. 비공개 시험 손실(hidden loss)은 정답에 **얼마나 높은 확률을 줬는지** 살펴봅니다.

정답이 ‘사과’인 빈칸 문제를 생각해 봅시다. 모델은 가장 높은 확률을 준 답을 씁니다.

| 모델 | 사과에 준 확률 | 배에 준 확률 | 포도에 준 확률 | 실제로 쓴 답 |
|---|---:|---:|---:|---|
| A | 40% | 35% | 25% | 사과 |
| B | 45% | 50% | 5% | 배 |

A는 사과를 써서 맞혔으므로 **최종 점수가 더 높습니다**. 하지만 정답인 사과에 준 확률은 A가 40%, B가 45%입니다. 그래서 A의 **비공개 시험 손실도 더 높습니다**. 이 예에서는 답을 단어 하나로 단순하게 보여 줬습니다. 실제 시험은 여러 단어의 위치를 비교해 점수를 매기고, 정답을 작은 조각으로 나눠 손실을 계산합니다.

## 종합 순위를 계산하는 법

1. 최종 점수가 높은 학생부터 **점수 순위**를 매깁니다.
2. 비공개 시험 손실이 낮은 학생부터 **시험 손실 순위**를 매깁니다.
3. 두 순위를 더해 2로 나눕니다. 두 순위를 50%씩 반영한 **평균 순위**입니다.
4. 평균 순위가 작은 학생부터 **종합 순위**를 매깁니다.

예를 들어 점수 순위가 3위이고 시험 손실 순위가 1위라면 평균 순위는 (3 + 1) ÷ 2 = 2.0입니다. 다른 학생의 평균 순위가 3.0이면 2.0인 학생이 앞섭니다. 같은 값은 공동 순위로 처리합니다. 두 학생이 공동 2위라면 그다음 학생은 4위입니다.

| 시험 손실 순위 | 비공개 시험 손실이 낮은 학생부터 매긴 순위입니다. |
| 평균 순위 | 점수 순위와 시험 손실 순위를 더해 2로 나눈 값입니다. |
| parameter | 매개변수 수입니다. 모델이 답을 고를 때 쓰는 숫자가 몇 개인지 나타냅니다. 모델 안에 조절 손잡이가 여러 개 있고 손잡이마다 숫자가 하나 적혀 있다고 생각하면 됩니다. |
| 추론 시간(초) | 학습이 끝난 모델이 시험 문제의 답을 모두 만드는 데 걸린 시간입니다. |
| 학습 시간(초) | 교수자 PC에서 제출한 코드로 모델을 처음부터 가르치는 데 걸린 시간입니다. |
| epochs | 학습 자료 전체를 몇 바퀴 공부하도록 설정했는지 보여 줍니다. 자료 전체를 한 번 공부하는 것이 1바퀴입니다. |
| epoch당 시간(초) | 학습 자료 한 바퀴에 걸린 평균 시간입니다. 예를 들어 100바퀴에 50초가 걸렸다면 한 바퀴에 평균 0.5초입니다. |
| commit | 채점에 사용한 제출본의 버전 번호 앞 7자리입니다. 같은 학생이 코드를 여러 번 고쳤을 때 어느 버전을 채점했는지 찾을 수 있습니다. |
