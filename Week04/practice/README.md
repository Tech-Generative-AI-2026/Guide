## 목표

원문을 GPT-2 토큰 ID로 바꾸고, sliding window로 다음 토큰 입력·정답을 만든 뒤 batch와 토큰·위치 임베딩의 합을 완성한다. 4주차 강의의 입력 데이터 구성 실습이다. 완성 지점은 `[B,T,D]` 입력 임베딩이며 모델 학습과 attention 계산은 포함하지 않는다.

## 제공 입력과 환경

제공 파일은 `README.md`와 `corpus.txt`다. Python 3.10 이상, PyTorch와 tiktoken이 설치된 수업 가상환경에서 CPU로 실행한다. 필요하면 해당 환경에서 `python -m pip install torch tiktoken`으로 설치한다.

원문은 아래 한 줄이며 읽을 때 파일 끝 줄바꿈만 제거한다.

```text
Every effort moves you forward. Every effort moves you forward. Today
```

GPT-2 인코더의 토큰 ID 13개는 다음과 같다.

```text
[6109,3626,6100,345,2651,13,3887,3626,6100,345,2651,13,6288]
```

문맥 길이 T=4, stride=4, batch 크기 B=2, 임베딩 차원 D=3이다. 토큰 표는 50257행, 위치 표는 4행이다. seed는 123으로 고정하고 float32를 사용한다. 토큰 임베딩 층을 먼저, 위치 임베딩 층을 나중에 만든다. 무작위 벡터의 수치 암기 대신 아래 구조와 관계를 검산한다.

## 처리 순서

1. 원문을 읽어 토큰화한다. decode로 원문이 복원되는지, ID가 사전 범위 안인지 확인한다.
2. 강의의 Dataset 구조로 길이 4 입력을 만들고, 시작점이 한 토큰 뒤인 길이 4 구간을 정답으로 만든다. 완전한 정답까지 존재하는 시작점 0,4,8만 사용하므로 sample은 3개다. stride는 다음 sample 시작점의 이동량이며 정답 offset은 항상 1이다.
3. 모든 sample에서 입력과 정답의 자료형·길이를 확인한다. 입력과 정답 각각을 원문의 해당 구간과 비교하여 마지막 정답 토큰까지 검사한다. `x[1:]==y[:-1]`도 확인한다.
4. DataLoader에 batch 크기 2, shuffle=False, drop_last=True, num_workers=0을 지정한다. 완전한 batch는 1개이고 남은 sample 1개는 제외된다. 첫 batch의 입력·정답은 `[2,4]`다.
5. 토큰 임베딩 `[2,4,3]`과 위치 임베딩 `[4,3]`을 더해 최종 입력 `[2,4,3]`을 만든다. 위치 0~3의 벡터가 모든 sample의 같은 위치에 더해져야 한다.
6. 합에서 토큰 임베딩을 뺀 값이 각 위치 임베딩인지 확인한다. 실수 비교에는 절대 오차 1e-6, 상대 오차 0을 허용하고 계산 중 반올림하지 않는다.

## 기대 결과

```text
inputs  = [[6109, 3626, 6100, 345], [2651, 13, 3887, 3626]]
targets = [[3626, 6100, 345, 2651], [13, 3887, 3626, 6100]]
token, position, input shapes: (2, 4, 3) (4, 3) (2, 4, 3)
OK: 13 tokens; 3 samples; 1 batch; input (2, 4, 3)
```

토큰 ID·sample 수·batch 수, 입력·정답, 각 임베딩의 shape와 최종 입력 벡터를 출력한다. 복원·정답 정렬·위치 덧셈 검산이 통과했음을 출력하고 모든 검사가 끝난 뒤 성공 문장을 표시한다.
